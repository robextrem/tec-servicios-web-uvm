## Instalación y ejecución Proyecto Semana 4

### Requisitos previos
- [Node.js](https://nodejs.org/) (v18 o superior recomendado)
- npm (viene incluido con Node.js)

### Instalación

1. Ve a la carpeta del proyecto:
```bash
   cd semana4
```

2. Instala las dependencias:
```bash
   npm install
```

### Ejecución

Levanta el servidor con:

```bash
node index.js
```

O, si tienes un script definido en `package.json` (por ejemplo `"dev": "node index.js"`):

```bash
npm dev
```

El servidor quedará corriendo en: localhost:3000
